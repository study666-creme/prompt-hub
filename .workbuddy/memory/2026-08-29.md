### 部署踩的三个坑（已记入 docs/DEPLOY-CHECKLIST.md）

1. **safe-delete 中断部署**：`stage-pages.ps1` 用 `Remove-Item` 清 `.pages-deploy`
   和 `legacy/styles/partials`，单回合超 50 个文件抛 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`。

2. **stage-pages.ps1 必须纯 ASCII**（最坑，排查了 4 轮）：文件是 UTF-8 **无 BOM**，
   Windows PowerShell 5.1 按系统 ANSI 解码，中文注释乱码会让解析器**吞掉紧随其后
   的赋值语句**，表现为 `New-Item -Path` 收到空值。极易误判成 `$env:TEMP` 未定义。
   诊断方法：写个临时 ps1 把 `$PSScriptRoot` / `$env:TEMP` 打到文件里——

3. **生产冒烟假失败**：`deploy-pages.ps1` 顶层 `$ErrorActionPreference="Stop"`，
   node 往 stderr 打的 `NODE_TLS_REJECT_UNAUTHORIZED` 警告被 PowerShell 当成
   `NativeCommandError` 抛出。看到 `Deployment complete` 就是成功了，
   别拿这一步的退出码判断。单独复核用 Bash 跑：
   `SMOKE_BASE=https://prompt-hubs.com node scripts/run-index-http-smoke.mjs`。
4. 另：PowerShell 5.1 里 `try {} catch {}` 空 catch 块会报 `UnexpectedToken`，
   单行 `if (...) { ... }` 在部分宿主下也不稳，部署脚本一律用多行 if 块。
